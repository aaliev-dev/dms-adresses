# DMS Adresses — карта клиник по ДМС

Инструменты для превращения перечня ДМС-клиник (из памятки застрахованного)
в удобную **карту на Яндекс Картах**, которой можно поделиться с коллегами.

Два способа показать адреса:

1. **Ссылка на Яндекс Карты** с метками (быстро, но на ~20–30 адресов —
   упирается в длину URL).
2. **Своя страница с картой на GitHub Pages** — все клиники на одной карте
   с кластеризацией, поиском, фильтром по услугам и балунами с телефоном
   и часами. Это то, что нужно для шейринга коллегам.

## Состав проекта

```
data/raw-dms-list.txt   — исходник: текст памятки с перечнем клиник
data/clinics.csv        — разобранные данные: адрес, клиника, телефон, часы, услуги
data/coords.json        — кэш геокодирования (адрес -> координаты)
addresses.txt           — все адреса по одному на строку (вход для ссылок)
parse_clinics.py        — парсер памятки -> clinics.csv + addresses.txt
parse_pdf.py            — добавляет разделы стоматологии (стр. 36–48) и экстренной
                          стационарной помощи (стр. 48–54) из PDF
fetch_websites.py       — официальные сайты клиник через «Поиск по организациям»
geocode.py              — геокодирование + ссылки на Яндекс Карты (с кэшем и чанкингом)
build_map.py            — генерация docs/ (страница карты для GitHub Pages)
docs/index.html         — карта на Яндекс JS API (собирается build_map.py)
```

Личных данных в репозитории нет — только публичный перечень клиник.

## Как это работает

Официального API, создающего «коллекции адресов» внутри аккаунта Яндекс
Карт, не существует, поэтому:

- адреса превращаются в координаты через **HTTP Геокодер** (бесплатный,
  нужен API-ключ);
- дальше либо собирается ссылка по URL-схеме (`ll` + `z` + `pt`), либо
  координаты кладутся в JSON и отрисовываются на странице через
  **JavaScript API**.

## Установка

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Получение API-ключей

1. Кабинет разработчика Яндекс: https://developer.tech.yandex.ru/
2. Создайте **три ключа** — у каждого отметьте свой продукт:
   - **HTTP Геокодер** (адрес → координаты) — `YANDEX_GEOCODER_KEY`;
   - **JavaScript API** (отрисовка карты) — `YANDEX_MAPS_JS_KEY`;
   - **Поиск по организациям** (сайты клиник) — `YANDEX_ORG_KEY`.
3. Скопируйте `.env.example` в `.env` и вставьте ключи (в git `.env` не попадает).

> Если геокодер отвечает `403 Forbidden` — у ключа не подключён продукт
> «Геокодер», ключ ещё не активирован (до 15 минут) или запрос идёт с
> зарубежного IP (Яндекс геокодер работает только с российских IP).

## Шаг 1. Разобрать памятку

```bash
python3 parse_clinics.py     # -> data/clinics.csv + addresses.txt
```

Парсер понимает распечатку таблицы: склеенные поля («д.5ООО «МедиАрт»…»),
переносы адресов и телефонов через строки, номера страниц.

В памятке, кроме амбулаторного раздела, есть отдельные таблицы
стоматологических клиник и стационаров экстренной помощи. Если есть PDF
памятки — добавьте их:

```bash
python3 parse_pdf.py "Имя файла.pdf"   # сам PDF в git не попадает
```

Итог — `data/clinics.csv` с ~760 клиниками (амбулаторные + стоматология +
экстренная стационарная помощь).

## Сайты клиник

В памятке сайтов нет — скрипт берёт их из «Поиска по организациям» Яндекса
по названию клиники (нужен ключ `YANDEX_ORG_KEY`, выполнять с российского IP):

```bash
python3 fetch_websites.py
```

## Шаг 2. Ссылки на Яндекс Карты (вариант 1)

```bash
python3 geocode.py                # из addresses.txt, красные метки
python3 geocode.py --style blue   # цвет меток
python3 geocode.py --dry-run      # только список адресов
```

Результат кэшируется в `data/coords.json` — повторные запуски не тратят
лимиты геокодера. Если адресов много, скрипт разобьёт ссылки на несколько
(по умолчанию не длиннее 1800 символов на URL).

## Шаг 3. Карта на GitHub Pages (вариант 2)

```bash
python3 build_map.py
```

Собирает `docs/index.html` + `docs/clinics.json`. Проверьте локально:

```bash
python3 -m http.server 8000 --directory docs
# откройте http://localhost:8000
```

### Публикация на GitHub Pages

```bash
git init && git add -A && git commit -m "Клиники по ДМС: карта"
gh repo create dms-adresses --public --source=. --push
gh api repos/<user>/dms-adresses/pages -f "source[branch]=main" -f "source[path]=/docs"
```

Карта станет доступна по адресу:
`https://<user>.github.io/dms-adresses/`

Обновление карты (после правок списка):

```bash
python3 parse_clinics.py && python3 build_map.py
git add -A && git commit -m "Обновление карты" && git push
```

## Примечания

- Ключ JS API — клиентский, он попадает в HTML страницы (так задумано
  Яндексом: ключ ограничен доменом, где размещена карта).
- Точность геокодирования зависит от формулировки адреса; пару спорных
  адресов из памятки (например, «г Звенигород, г Одинцово») стоит
  проверить глазами.
- Лимиты геокодера: бесплатный тариф — тысячи запросов в день, для
  ~450 адресов хватает с запасом.
